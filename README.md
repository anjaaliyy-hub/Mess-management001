🍽️ MessMate – College Mess Management Website

A simple and user-friendly College Mess Management System developed to make everyday mess activities easier to manage. MessMate brings food menus, student attendance, food polls, expenses, payments, and student suggestions together in one website.

✨ Features

- Login System – Separate demo access for students and administrators.
- Dashboard – View a summary of mess activities.
- Food Menu – View and manage daily food menus.
- Attendance Management – Mark daily check-in and check-out.
- Food Poll – Vote for the food you would like to have tomorrow.
- Expense Management – Record mess-related expenses.
- Payment Records – Maintain student payment records.
- Food Suggestions – Submit suggestions for future meals.
- Feedback – Share feedback about mess services.
- Leave Requests – Submit leave requests for admin approval.
- Admin Dashboard – Manage menu items, view students, and export reports.

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Functionality and interactions
- Local Storage – Saving demo data in the browser

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure these three files are present:
   - "index.html"
   - "style.css"
   - "script.js"
4. Install the Live Server extension in VS Code.
5. Right-click "index.html".
6. Select Open with Live Server.

The website will open in your browser.

⚠️ Project Note

This is a beginner-level academic project built using HTML, CSS, and JavaScript. It uses browser Local Storage to save demo data. The data is stored locally in the browser and does not automatically sync between different devices or users. Login credentials are for demonstration and are not production-secure.

🎯 Project Objective

The main objective of MessMate is to demonstrate how a simple web application can help organize college mess activities and improve communication between students and mess administrators.
